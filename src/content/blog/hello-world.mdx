# Welcome to Astro Static Boilerplate

This is a sample post demonstrating MDX and Astro content collections.

## Key Benefits
- **Zero Client-Side JavaScript** by default for lightning-fast speeds and perfect Lighthouse scores.
- **Static HTML Output**: Pure HTML, CSS, and optimized assets ready for Hostinger Apache hosting.
- **Design Tokens**: Centralized Tailwind design tokens in `src/styles/tokens.css`.
- **Content Collections**: Type-safe frontmatter validation with Zod.

## Code Example

```typescript
// Astro server-rendered logic
const greeting = "Hello, Fast Web!";
console.log(greeting);
```

You can write standard Markdown or embed `.astro` components directly in MDX.
